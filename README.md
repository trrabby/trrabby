[**Live**](https://ramadantimer-bd.netlify.app) · [Client Code](https://github.com/trrabby/moonlit-prayer-times.git) · [Server Code](https://github.com/trrabby/ramadanTimerBackend.git)

- Displays Sehri End, Fajr, and Iftar times for every day of Ramadan with automatic highlighting of the current day.
- Includes scroll‑to‑today functionality, sticky table headers, and fully responsive dark/light mode.
- Users can submit ratings and feedback with name, email, and comments; edit or delete their own reviews.
- Integrated contact system with EmailJS, WhatsApp, and email quick‑action buttons.

**Tech:** Node.js, Express.js, MongoDB, React.js, JavaScript, Tailwind CSS, ShadCN UI, EmailJS, Local Storage, Lucide React, Responsive Design, Form Validation.
